# BLACK BULLS GRIMOIRE — Personal Strength System

> **Private. Made for one Bull only (me). Not for sharing, not for distribution.**
> This app was designed and customised for my own use. Please do not share, post or redistribute it.

Black Clover × Solo Leveling training app. Whole-body bodyweight strength + isometric holds, daily.
South Indian budget diet. Level/rank/XP system. Works offline. No videos, no Drive links.

## Daily motivation
7 speeches in the spirit of Asta and Yami, one per weekday. Shown once each morning and as a card on the Quest tab. Edit them in `SPEECHES` in `js/data.js`.

## Run / host (privately)
Serve the folder from a **private** location. Opening `index.html` directly works for the UI; install + offline need http(s).
Keep any GitHub repo **private** (Settings → Danger zone → Change visibility). Do not enable public Pages.

## Install on phone
Open the URL once → Chrome ⋮ → *Install app*, or Safari Share → *Add to Home Screen*.

## Editing
- Exercises, weekly split, diets, speeches: `js/data.js`
- Look & feel: `css/style.css`
- After changing any file, bump `VERSION` in `sw.js` so phones refresh the cache.
